# Book Tracker

**Автор:** Иван Иванов

## Описание программы

Book Tracker — простое приложение для учёта прочитанных книг. Позволяет добавлять книги с указанием названия, автора, жанра и количества страниц. Есть фильтрация по жанру и количеству страниц. Все данные сохраняются в файл `books.json`.

## Инструкция по запуску

1. Установите Python 3.8+.
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/book-tracker.git
   cd book-tracker
   ```
3. Запустите приложение:
   ```bash
   python book_tracker.py
   ```
4. (Опционально) Создайте виртуальное окружение.

## Примеры использования

- Добавьте книгу: введите все поля и нажмите «Добавить книгу».
- Примените фильтр: введите жанр или количество страниц и нажмите «Применить фильтр».
- Данные сохраняются автоматически при добавлении книги.
